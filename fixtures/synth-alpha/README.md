# Native synthesis alpha contract fixtures

These files are Milestone 0 design evidence and active implementation targets for [`plan-synth.md`](../../plan-synth.md). They are non-normative, readable source snapshots using the reserved `crump-module 2-alpha` header. Each form becomes executable only through a complete capability slice; production Crump source version 1 rejects unfinished forms rather than accepting them as runtime no-ops.

| Fixture | Contract role |
| --- | --- |
| `hybrid-synth.crump` | Representative complete Instrument: eight source classes, explicit voice/shared domains, presentation sections, macros, stable Modulation Sources/routes, auxiliary scaling, audio-rate PM, serial filters, and shared effects. |
| `minimal-wavetable.crump` | Small exact-WAV table playback/import contract. |
| `minimal-sample-source.crump` | Small repitched sample-source contract; no implicit time stretch. |
| `minimal-multisample.crump` | Readable key/velocity zone contract. |
| `minimal-granular.crump` | Fixed-pool deterministic grain contract. |
| `minimal-spectral.crump` | Bounded sinusoidal-peak analysis/resynthesis contract. |
| `maximum-topology.crump` | Named `qualification-max-v1` profile generated by `generate_max_fixture.py`. |

The WAV files under `media/` were generated from mathematical functions and a fixed integer sequence by `generate_assets.py` for this repository. They are original Crump fixtures distributed under the repository's MPL-2.0 license. `manifest.json` records their exact hashes and intended uses.

`maximum-topology.crump` is a maximum **qualification profile**, not permission to combine every independent structural ceiling. Aggregate admission must still reject Projects exceeding work, state, immutable-program, latency, or two-runtime publication budgets.
