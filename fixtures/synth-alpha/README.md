# Native synthesis alpha contract fixtures

These files began as Milestone 0 design evidence and remain the capability fixtures for [`plan-synth.md`](../../plan-synth.md). Completed vertical slices and the combined qualification profile use stable source version 2 and must parse, validate, compile, and render. The unfinished representative `hybrid-synth.crump` design snapshot remains `crump-module 2-alpha` and fails closed rather than becoming a runtime no-op. `manifest.json` records the status and exact hash of each fixture.

| Fixture | Contract role |
| --- | --- |
| `hybrid-synth.crump` | Representative complete Instrument: eight source classes, explicit voice/shared domains, presentation sections, macros, stable Modulation Sources/routes, auxiliary scaling, audio-rate PM, serial filters, and shared effects. |
| `minimal-wavetable.crump` | Runnable source-v2 exact-WAV table Project. |
| `wavetable-demo.crump` | Runnable source-v2 table-position, morph, warp, Modulation, unison, and Audition Phrase Project. |
| `minimal-sample-source.crump` | Runnable source-v2 slices, direction, gated playback, loops, and repitch-only rate Project. |
| `minimal-multisample.crump` | Runnable source-v2 readable key/velocity/layer/round-robin zone Project. |
| `minimal-granular.crump` | Runnable source-v2 fixed-pool deterministic grain Project. |
| `minimal-spectral.crump` | Runnable deterministic bounded sinusoidal-peak analysis/resynthesis Project. |
| `maximum-topology.crump` | Runnable named `qualification-max-v1` combined profile generated by `generate_max_fixture.py --check`; its eight-note chord intentionally crosses the seven-voice admitted boundary through deterministic stealing. |
| `maximum-granular-spectral.crump` | Runnable independent-ceiling profile with two 64-slot granular and two 128-peak spectral sources per voice; five voices are admitted and six are a checked transition-work rejection. |

The WAV files under `media/` were generated from mathematical functions and a fixed integer sequence by `generate_assets.py` for this repository. They are original Crump fixtures distributed under the repository's MPL-2.0 license. `manifest.json` records their exact hashes and intended uses. `basic-table.wav` is the runnable four-frame starter table; its consecutive 2,048-sample mono frames are the authoritative bytes used by both stable wavetable fixtures. `sample-source.wav` and the two multisample-zone WAVs are the runnable sample-derived sources; exact original frames remain authoritative while decoded Project-rate stereo frames and spectral peak analyses are disposable.

`maximum-topology.crump` is a maximum **qualification profile**, not permission to combine every independent structural ceiling. Its exact admitted values are recorded in `manifest.json`; raising the combined profile to eight resident voices is rejected by the two-runtime transition-work budget. Aggregate admission must still reject Projects exceeding work, state, immutable-program, latency, or publication budgets. `maximum-granular-spectral.crump` therefore qualifies the independent per-voice granular and spectral ceilings separately instead of pretending those ceilings fit into every combined maximum.
