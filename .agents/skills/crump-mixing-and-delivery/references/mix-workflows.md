# Mix workflows

## Parallel compression

1. Route an explicit source/tap to one shared Return.
2. Compress aggressively for density, not replacement.
3. Filter lows/highs that destabilize the blend.
4. Match Return output before judging.
5. Blend underneath the intact transient path.

## Sidechain space

1. Name the foreground detector source.
2. Duck only the competing band or ambience when full-band pumping is unnecessary.
3. Set attack/release from phrase and groove.
4. Confirm gain reduction returns to zero naturally.
5. Compare in context, not in solo only.

## Delay throw

1. Use a shared filtered Delay Return.
2. Automate Send on selected words/hits.
3. Set feedback for the available gap and tail boundary.
4. Duck or de-ess the wet path if it masks the source.
5. Check the next section entry.

## Width without weak mono

1. Keep the bass/fundamental region centered.
2. Create decorrelation or delay only above the chosen crossover.
3. Control anti-phase energy and level-match.
4. Check mono fold-down throughout modulation movement.
5. Avoid treating width as a loudness control.

## Multiband control

1. State which band and event cause the problem.
2. Choose stable crossovers and inspect recombination.
3. Set detector/filter and dynamics only for that role.
4. Keep adjacent bands mostly inactive unless independently justified.
5. Compare against a single-band alternative.

## Reverb depth

- Short/dark ambience for proximity glue.
- Predelayed plate/room for a foreground source with space around the attack.
- Long filtered tail for transitions and background depth.
- Automate Send rather than inserting one static wash everywhere.

## Master qualification

1. Confirm no source or bus clips unexpectedly.
2. Compare pre/post Master at matched loudness.
3. Measure sample peak, reconstructed peak, loudness/LRA where available, DC, and non-finite values.
4. Check beginning, loudest passage, section transitions, and complete tail.
5. Verify file and manifest hashes after final write.
