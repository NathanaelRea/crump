# Completion report template

```markdown
## Crump change

- Candidate before: `REVISION`
- Active before: `REVISION`
- Active after: `REVISION`
- History entry: `ENTRY_ID`
- Origin/actor: `agent` / `NAME`

### Authored changes

- `file.crump`: durable IDs and concise change
- `media/asset.wav`: source identity, transform, provenance, and hash

### Verification

- `validate`: pass/fail
- `check`: pass/fail or not applicable
- audition: target, path, range, loop, and A/B method
- render: paths, range, frame count, hashes, and analysis

### Listening decision

Describe what the musician should compare at matched level and which choice remains subjective.

### Remaining issues

List unsupported requests, diagnostics, conflicts, external dependencies, or evidence not collected.
```

Do not omit a failed check, unresolved diagnostic, approximation, or Candidate/Active mismatch.
