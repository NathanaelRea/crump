# Contributor Guidance

## Agent skills

### Issue tracker

Issues are tracked as local Markdown files under `.scratch/`; external pull requests are not a request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The tracker uses the standard `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` states. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with `CONTEXT.md` at the root and architectural decisions under `docs/adr/`. See `docs/agents/domain.md`.
