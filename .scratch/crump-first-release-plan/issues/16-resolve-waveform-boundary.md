# Resolve the Terminal Waveform-Editing Boundary

Type: prototype
Mode: HITL
Status: resolved
Blocked by: [12 - Freeze the Native Release Capability Floor](12-freeze-native-capability-floor.md), [13 - Freeze the First-Release Workspace Interaction Contract](13-freeze-workspace-contract.md)

## Question

Which waveform and spectrum inspection operations are useful in the terminal, and do trimming, looping, and fades admit a source-backed interaction good enough for inclusion while deeper editing remains external?

## Research Baseline

Before prototyping, research Ableton's official clip, sample, fade, waveform, and spectrum workflows first, then compare professional DAWs and dedicated audio editors. Record which operations are essential to finishing the reference project and which are specialist conveniences. Use that baseline to keep only terminal interactions that are precise and clearly better than source-only or external editing.

## Answer

Deferred. The First Public Release is synthesis-complete for its no-sample Reference Project and needs only playhead, Event/instrument activity, safe levels, and graph/Parameter state. Waveform, spectrum, sample trimming/looping/fades, destructive editing, and model-rendered waveform assets may return only if human evidence selects them as a later Validated Slice.
