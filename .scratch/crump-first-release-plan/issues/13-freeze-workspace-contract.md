# Freeze the First-Release Workspace Interaction Contract

Type: grilling
Mode: HITL
Status: open
Blocked by: [09 - Evaluate the Authoring Prototype With a Representative Musician](09-evaluate-authoring-with-musician.md), [10 - Freeze the DSL and Project-Source Contract](10-freeze-dsl-contract.md), [12 - Freeze the Native Release Capability Floor](12-freeze-native-capability-floor.md)

## Question

Which Timeline, Event Grid, Instrument Faceplate, exact Parameter, inspectable Graph View, source, diagnostics, Active Revision, Project History, activity/level, keyboard, and optional mouse interactions are mandatory for the Musical Sketch workflow, and which graph operations remain source- or Agent-only?

## Research Baseline

Use issue 09's two-role evaluation and ADR 0006. Require visible focus, searchable help, exact value entry, keyboard completeness, optional mouse selection, contextual explanations, and no precision drag dependency. Exclude mixer, routing, Automation, browser, waveform, spectrum, oscilloscope, and structured graph-topology views.
