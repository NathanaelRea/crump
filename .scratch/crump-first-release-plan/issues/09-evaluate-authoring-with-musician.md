# Validate the Progressive Authoring Workflow

Type: prototype
Mode: HITL
Status: open
Blocked by: [08 - Prototype the Code and TUI Authoring Balance](08-prototype-authoring-balance.md)

## Question

Can a terminal-capable Beginner Musician understand and change a Musical Sketch through the Timeline, Event Grid, Instrument Faceplate, Graph View, contextual explanations, and Project History without editing source, while an Experienced Producer can transfer existing concepts and reach exact Parameter, graph, and source depth?

## Research Baseline

Use the canonical first-release workflow rather than the superseded professional-DAW gate. Prototype the smallest reaction artifact that exercises the Timeline, Event Grid, Faceplate, inspectable Graph View, Agent Change explanation, append-only History Restore, keyboard completeness, and optional mouse selection. Evaluate the Beginner Musician and Experienced Producer roles separately; neither result substitutes for the other.
