# ADR 0010: Small Declarative Project Language

Status: Accepted
Date: 2026-07-28

Crump will keep a purpose-built declarative DSL as the shared source for humans, Production Views, Authoring Agents, validation, and playback rather than using structured data alone or embedding a general-purpose language. The First Public Release grammar is restricted to concepts exercised by the Musical Sketch and graph-instrument workflow; new syntax does not enter merely to satisfy the complete-track destination. This preserves readable and safely rewritable domain semantics without accepting arbitrary execution or building a second general programming platform.
