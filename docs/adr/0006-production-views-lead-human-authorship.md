# ADR 0006: Production Views Lead Human Authorship

Status: Accepted
Date: 2026-07-28

Production Views are the primary human authorship surfaces; direct DSL editing remains available. Timeline, Event Grid, Faceplate, Parameters, Automation, Processing, Graph, Source, Diagnostics, and History views reveal different depths of the same authored objects rather than creating separate beginner and expert models.

Procedural musical material remains visible and is not flattened by a shallow grid edit. Every durable Production View operation is a Structure-Preserving Source Edit. Graph topology creation, deletion, and reconnection remain source or Agent operations.
