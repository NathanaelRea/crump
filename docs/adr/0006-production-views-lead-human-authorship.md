# ADR 0006: Production Views Lead Human Authorship

Status: Accepted
Date: 2026-07-28

Crump's Production Views will be the primary human authorship surfaces; direct DSL editing remains always available but is not required for the ordinary workflow. The First Public Release includes the clip Timeline, concrete-event grid, Instrument Faceplate, exact Parameter views, and an inspectable Graph View; mixer, routing, Automation, and structured graph-topology views enter only through later Validated Slices. Each view progressively reveals more control over the same authored objects rather than introducing separate beginner and expert modes. Procedural musical material remains visible but cannot be flattened by a shallow grid edit. This preserves human-readable source for exact control, Agent authorship, and versioning while allowing beginners to learn through recognizable production concepts and experienced producers to transfer existing skills. Every durable Production View operation remains a Structure-Preserving Source Edit, so the interface does not introduce a second project model.
