# Triage Labels

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | Reporter input is required. |
| `ready-for-agent` | `ready-for-agent` | An AFK agent can proceed without more context. |
| `ready-for-human` | `ready-for-human` | Human participation or implementation is required. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

Use the local status exactly as shown whenever an engineering skill refers to a canonical triage role.
