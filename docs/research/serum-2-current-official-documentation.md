# Serum 2 official documentation availability

- **Accessed:** 2026-08-22
- **Evidence policy:** Xfer Records primary sources only for Serum facts
- **Related research:** [`serum-2-capabilities-and-plugin-architecture.md`](serum-2-capabilities-and-plugin-architecture.md)

## Scope

The research environment provided no network-capable retrieval tool, and no full Serum 2 reference manual, official release-note corpus, or authenticated Xfer support corpus was available locally. No new Serum facts were established beyond the two Xfer primary sources already assessed in the related research. Unresolved exact-comparison questions are therefore recorded as **official evidence unavailable—do not guess** rather than verified or inferred.

This is an evidence-access limitation, not evidence that Xfer publishes no additional documentation. The existing capability map remains the verified comparison basis: Xfer's official [Serum 2 product page](https://xferrecords.com/products/serum-2) and [*What's New in Serum 2*](https://static.xferrecords.com/Serum%202%20What%27s%20New.pdf), identified there as Serum 2 version 2.0, manual version 1.0.0, dated March 17, 2025. The PDF is a feature overview rather than a complete reference manual. See the [existing evidence assessment](serum-2-capabilities-and-plugin-architecture.md#source-scope-and-confidence).
