# Crump icon

**Selected design: Glacier.** Cyan sine waves transition through triangles into blue square waves, together forming a C on a midnight navy tile.

| File | Use |
| --- | --- |
| [master.png](master.png) | Original full-resolution artwork |
| [icon.png](icon.png) | 512px application icon |
| [icon-192.png](icon-192.png) | 192px application/web icon |
| [apple-touch-icon.png](apple-touch-icon.png) | 180px touch icon |
| [favicon.ico](favicon.ico) | Browser icon with 16, 32, and 48px frames |
| [favicon-16.png](favicon-16.png), [favicon-32.png](favicon-32.png), [favicon-48.png](favicon-48.png) | Individual PNG favicon sizes |

These exports preserve the selected Glacier artwork and transparent outer corners. The detailed mark is reduced directly at small sizes.

The artwork was created using the built-in imagegen tool. The [Glacier prompt](../../design/crump-icons/SWEEP.md#glacier) and [comparison studies](../../design/crump-icons/sweep.html) are retained with the design explorations. ImageMagick was used only for size and format exports.
